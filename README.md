# 留学目的地探索

这是一个无需构建步骤的静态问答网页，题目与目的地画像在 dist/quiz-data.js，原始结果文案及逐项适配说明在 dist/result-material.js，样式与交互分别在 dist/styles.css 和 dist/app.js。

## 题库整理

- 保留了原素材中的 8 个生活情境与每题 4 个选项，把较长的角色标签和攻击性表达收短，方便手机阅读。
- 每个选项沿用题目文件里的目的地标签，选择后给对应结果画像累计一条线索。同一选项里重复指向同一画像的标签只计一次。
- “南欧”映射到西班牙 / 意大利画像，“北欧”映射到北欧画像，“内耗型”作为英国画像的情绪线索处理。
- “间隔年 / 工作后申请”在原选项中没有直接对应标签；当用户多次选择暂停、休息或重新消化压力的选项时，展示为申请节奏建议。
- “全维度适配”同样没有直接对应选项；当目的地线索分散且接近时，作为隐藏结果展示，并列出得分靠前的方向。
- 多个画像并列时，以最近一次答案中的匹配线索优先。

结果页会说明画像与作答线索如何对应，提供环境偏好、可核实事项和相近备选方向；原始画像的金句、判词、隐藏刚需和占比收在展开区。原始素材中的“全服占比”没有统计来源，页面明确标注为趣味设定，不代表真实人群比例。所有目的地结果都是偏好灵感，不代表院校录取、费用、签证、就业或移民判断；做实际决定时仍需核实具体项目与当年要求。

网页入口会按北京时间生成每日密码：将当天的 `YYYYMMDD` 数字倒序输入。每个浏览器标签页的首次成功登录计一次，同一标签页当天刷新不会重复计数；同一浏览器配置在每个网址每天最多成功登录两次。两个公开网址的浏览器存储互不共享，清除浏览器数据也会重置本地次数。由于这是公开的静态网页，密码校验和计数都在浏览器端运行，只能作为日常访问门槛，不能保护源码或抵御绕过；真正限制访问需要服务端身份验证。

source-material/ 目录保存原始题目和结果。网页数据是适配交互后的编辑版，原始素材保持不变，便于后续继续校对。
